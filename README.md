# Purr Haven 🐾

**Better care. Happier cats.**

Purr Haven is a cat-focused website concept designed to bring cat owners
and cat lovers together through care information, breed resources,
product categories, stories, and community updates.

## Overview

The website presents a welcoming homepage with a cat-themed visual
design. It introduces visitors to the Purr Haven brand and provides
navigation to different areas of the site.

## Features

-   **Responsive navigation:** Main navigation links for Home, About,
    Breeds, Care Guide, Blog, and Shop.
-   **Hero section:** Welcome message, introductory text, cat image, and
    an Explore Now call-to-action.
-   **Feature highlights:** Sections promoting expert care advice,
    premium products, breed guides, and cat stories.
-   **Browse by Category:** Category cards for Health & Care, Food &
    Nutrition, Toys & Accessories, and Adoption & Rescue.
-   **Newsletter area:** Email input and subscription button for
    visitors who want updates.
-   **Instagram-style gallery:** A visual grid featuring cat
    photographs.
-   **Search popup:** Search interface with an input field and search
    button.
-   **Footer:** Brand information, social media icons, and grouped
    navigation links.

## Technologies Used

-   **HTML5** -- structures the website and its content.
-   **CSS3** -- styles the layout and visual appearance through
    `style.css`.
-   **JavaScript** -- supports interactive elements through `script.js`.
-   **Google Fonts** -- DM Sans and Playfair Display.
-   **Font Awesome 6.5.2** -- provides icons.
-   **Unsplash** -- supplies the cat photographs used on the page.

## Project Structure

Keep the website files together in one folder:

``` text
purr-haven/
├── index.html
├── style.css
├── script.js
└── README.md
```

-   `index.html` contains the page structure and content.
-   `style.css` contains the website styling.
-   `script.js` contains the JavaScript interactions.
-   `README.md` documents the project.

## Getting Started

1.  Download or clone the project files.
2.  Make sure `index.html`, `style.css`, and `script.js` are in the same
    folder.
3.  Open `index.html` in a web browser.

You can also use Visual Studio Code with the Live Server extension to
run the website locally.

## Notes

-   The HTML links to `style.css` and `script.js`; these files must be
    present for the complete styling and interactive behaviour.
-   The HTML includes navigation links and calls to JavaScript functions
    such as `exploreNow()` and `performSearch()`. Their behaviour
    depends on the corresponding JavaScript implementation.
-   Some navigation destinations and footer links are section anchors or
    placeholders. Ensure the matching sections or real destinations are
    added if those links are intended to navigate to separate content.
-   The newsletter form is presented in the interface; an actual
    subscription service requires a backend or a connected form service.
